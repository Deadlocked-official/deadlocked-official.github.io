Discord bot

Deadlocked in your Discord

Builds, counters, the meta and patch notes as slash commands, right where you and your friends already talk. It answers from the same data as this site, so it's always up to date.

Add to Discord You need to be an admin of the server. It only asks to send messages and post embeds.

Commands

Type / in any channel and pick a Deadlocked command. Hero and item names autocomplete.

/build haze

The hero's build: style, skill order, items for each phase and what to sell.

/counter vyper

Hardest and easiest matchups, plus items that win more against them.

/guide seven

Role, playstyle, skill tier and every ability.

/tier

How much practice each hero takes. Add a hero for just that one.

/item headhunter

Grade, stats, what it builds into and who buys it.

/meta

The heroes winning most over the last 7 days.

/patch

What changed in the latest game patch, number by number.

/player name

A player's rank and most-played heroes, by Steam name.

/quiz

Today's hero quiz and aim challenge, to play with friends.

/weekly-here

Posts "What changed this week" in that channel every Monday. Server managers only.

Good to know

Same data as the site

The bot reads the builds, tiers, guides and patch notes this site rebuilds every week, and checks live stats for /meta and /player.

Sometimes offline

It's a small fan project running on a personal computer, so it isn't online around the clock. If it doesn't answer, try again later.

What it can see

Only the commands you send it. It doesn't read your chat, and it only needs permission to send messages and embeds.

Unofficial fan site and bot. Not made by or affiliated with Valve or Discord.
